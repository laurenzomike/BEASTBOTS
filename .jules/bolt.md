## 2025-03-04 - Array.filter and Map grouping optimizations
**Learning:** Found an N+M opportunity by replacing a nested loop filter inside a map: mapping over BOT_TYPES while searching within `bots`. Also found that redundantly calling `.toLowerCase()` inside a frequent `.filter` block causes a performance hit from unnecessary string allocation and manipulation in hot loops. The impact can drastically scale back execution time.
**Action:** When filtering paired arrays (like definitions vs. active instances), build an `O(1)` Map instead of `O(N)` nested searches inside a map, reducing total iterations from `O(N*M)` to `O(N+M)`. When filtering against a user search term, always cache `searchTerm.toLowerCase()` outside the loop rather than re-evaluating it for every iteration.
