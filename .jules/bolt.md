## 2024-06-13 - Array filtering in hot render paths
**Learning:** In React components with frequent state updates (like App.tsx rendering lists with search and status filters), inline array `.filter()` callbacks recalculate on every render. If invariant operations like `.toLowerCase()` on the search query are done inside the loop, the cost becomes O(N) string creations per render, leading to significant CPU overhead and possible UI stuttering.
**Action:** Extract invariant computations like `.toLowerCase()` outside the `.filter()` callback. Apply short-circuit evaluation by checking less expensive conditions (like exact string matches) first, and wrap the entire derived state calculation in `useMemo` to prevent recalculation unless the source array or filter conditions change.
