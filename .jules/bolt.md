## 2024-06-14 - Extracting Invariant Computations and Short-Circuiting React Array Filters
**Learning:** When filtering arrays in React components, calculating variables like `searchQuery.toLowerCase()` inside the `.filter()` callback results in O(N) redundant string allocations and operations. Additionally, checking expensive operations (like string `.includes()`) before simple boolean/equality checks (like `status === statusFilter`) wastes CPU cycles.
**Action:** Always wrap derived state arrays in `useMemo`, extract invariant computations (e.g., lowercasing search terms) *outside* the `.filter()` callback but *inside* the `useMemo` block, and order filter conditions to evaluate inexpensive, short-circuiting checks (like status matching) before expensive ones (like string matching).
