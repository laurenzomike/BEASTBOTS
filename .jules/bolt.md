## 2026-06-19 - React useMemo array filtering & Short Circuit Evaluation Optimization
**Learning:** In a React functional component processing array filtering, repeatedly converting identical search queries using `toLowerCase()` inside the `.filter()` loop is a significant O(N) performance bottleneck. Combined with executing heavy string operations BEFORE checking lightweight boolean conditions, it creates severe render inefficiency, especially as the number of elements scales.
**Action:** Always wrap derived filtering state in `useMemo`. Pre-compute invariant variables (like `searchQuery.toLowerCase()`) outside the loop but inside the memoization block. Inside the filter, implement short-circuit evaluation by checking lightweight `boolean` comparisons (like `status === filterStatus`) first, and `return false` early before evaluating heavier string or regex methods.
