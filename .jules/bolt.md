## 2026-06-06 - Array .find() inside .map() is an O(N*M) React Render Anti-Pattern
**Learning:** Found a classic React anti-pattern in `AppFleetGrid.tsx` where a `.find()` operation on the `globalActivities` array was placed directly inside an `activeBots.map()` render loop. This caused a severe O(N*M) time complexity bottleneck. By extracting this logic into a `useMemo` hook and building a Map, the complexity was reduced to O(N+M). Importantly, when converting `.find()` behavior to a Map lookup, iterating forward and using `if (!map.has(key))` is required to ensure the Map caches the *first* matching element, preserving exact parity with `Array.prototype.find()`.
**Action:** Always scan React render loops (`.map()`) for nested array iteration methods (`.find()`, `.filter()`, `.reduce()`). Extract them into O(1) Lookup Maps constructed via `useMemo` outside the loop.
