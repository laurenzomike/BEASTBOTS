## 2025-02-28 - Consolidating Render Loops in React
**Learning:** In complex dashboard components (like `AppFleetGrid`), doing multiple independent operations on the same array (like `.filter`, `.reduce`, `.map`, and nested `.find`) inside the render loop causes significant O(N) overhead during re-renders, adding up to nearly 300ms in some scenarios when mocked with large datasets. Using `.find()` inside a `.map()` exacerbates this, causing an O(N*M) performance penalty on every render.
**Action:** When working on array-heavy React components, always consolidate multiple array passes into a single `for` loop wrapped in `useMemo`. When pairing two arrays together in the render tree, build a lookup `Map` inside `useMemo` first to guarantee O(1) access time during the JSX rendering phase.
