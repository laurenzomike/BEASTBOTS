## 2024-05-18 - [Optimizing Array Filters in React Renders]
**Learning:** Re-computing values on every iteration of a `.filter()` call (like `searchQuery.toLowerCase()`) when the value is actually invariant across the loop creates a significant N-scale redundant work bottleneck. Combining this with missing memoization (re-evaluating on every component render) severely degrades performance. Placing expensive string manipulations (like `.includes()`) before inexpensive checks (like strict equality) further compounds the delay.
**Action:** Always wrap derived filtering logic in `useMemo`. Extract loop invariants (e.g. `toLowerCase()`) outside the `.filter` loop but inside the memoization block. Order boolean checks in the filter function so fast, short-circuit operations occur first.
