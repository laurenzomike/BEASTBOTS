## 2024-06-12 - React Array Filtering Optimization
**Learning:** In React components with frequent renders (like `App.tsx` handling many states), unmemoized array filtering on complex objects causes redundant O(N) operations every render. Additionally, chaining expensive operations like `.toLowerCase()` and `.includes()` on every item without short-circuiting on simpler conditions (like exact string matches) compounds the performance hit.
**Action:** Always wrap derived array state in `useMemo`. Cache invariant operations (like `searchQuery.toLowerCase()`) outside the `.filter` loop but inside the `useMemo`. Use short-circuit evaluation by checking simple conditions first (e.g., `statusFilter === "all" || bot.status === statusFilter`) before falling back to expensive string comparisons.
