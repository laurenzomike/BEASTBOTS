## 2024-06-25 - [AppFleetGrid O(N*M) Render Cycle]
**Learning:** React component rendering paths in this codebase (like `AppFleetGrid`) can silently suffer from severe O(N*M) performance bottlenecks if `.find()` is used on unindexed data within a `.map()` during render (e.g. `globalActivities.find(a => a.botId === bot.id)` inside `bots.map`). This scales poorly as both agent fleets and activity logs grow. Additionally, computing multiple summary stats by running independent `.filter` and `.reduce` passes over the same large array scales at O(K*N) instead of O(N).
**Action:** Always pre-calculate lookup Maps `O(1)` using `useMemo` before rendering mapped lists to reduce `O(N*M)` complexity to `O(N+M)`. Consolidate multiple array traversals into single `useMemo` loops to compute derived arrays and aggregate metrics simultaneously.
