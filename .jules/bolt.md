## 2024-05-01 - AuditView React Performance Optimization
**Learning:** React components dealing with large datasets (like `activities` in `AuditView.tsx`) are prime candidates for optimization. Unmemoized complex derived state calculations mapping over large arrays (`activities`, `bots`) cause heavy computation during every single render. Combining multiple O(N) filtering/mapping operations into single passes drastically cuts down execution time.
**Action:** Use `useMemo` to memoize the computationally expensive derived variables (like filtering activities, counting stats, calculating efficiency ratios) in components that receive frequent updates to props or state (e.g., `chartMode` change in `AuditView.tsx` will cause re-render and re-execution of all filtering if unmemoized). Combine array traversals (like filtering activities by type multiple times) into a single loop using `useMemo` for O(N) processing instead of O(m*N).
