## 2024-05-18 - React List Filtering Memory Allocations
**Learning:** In complex React applications, naive list filtering (`bots.filter(b => b.name.toLowerCase().includes(search.toLowerCase()))`) creates redundant $O(N)$ string allocations because `search.toLowerCase()` is executed on every iteration. While small lists don't show the impact, as the `bots` or `activities` lists grow, this causes noticeable main-thread jank during typing. Additionally, derived sets (like extracting `uniqueBots` via map/set) will re-compute on every render if not memoized, which is particularly expensive.
**Action:** Always wrap derived filtering logic in `useMemo`. Crucially, extract loop-invariant computations (like converting the search query string to lowercase) *outside* the array traversal but *inside* the `useMemo` block. If calculating a derived `Set` from a list, always `useMemo` that as well. Ensure not to delete required variables during refactoring.
