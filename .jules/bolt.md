## 2024-05-24 - Array.prototype.find in Hot Render Paths\n**Learning:** In a highly reactive, component-heavy structure like AppFleetGrid mapping over bots, invoking Array.prototype.find() inside a render map triggers O(N*M) lookup times on every render cycle which can significantly block the UI thread during frequent updates (e.g. log activity).\n**Action:** When filtering or mapping components that require relational data lookups within hot render paths, preemptively resolve those lookups by building a Map with useMemo(). An O(1) Map.get() replaces the expensive O(N) array scan.
