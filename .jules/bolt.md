## 2025-02-28 - Optimize AppFleetGrid derived state and lookups
**Learning:** In a highly dynamic list of agents (where multiple instances update their status via snapshot listeners), calculating derived state using consecutive array operations (`filter().filter()`, multiple `reduce()`) causes redundant O(N) traversals per re-render. Additionally, using `.find()` inside a `.map()` on an array that grows linearly (like `globalActivities`) turns an O(N) rendering loop into O(N*M), severely degrading React render performance.
**Action:** When working with derived state from large arrays in React, consolidate traversals into a single pass using standard `for` loops inside `useMemo`. When pairing two arrays together (like bots and logs), build an O(1) Lookup Map (`Map<string, string>`) instead of using `.find()` inside a `.map()` to keep complexity linear O(N+M) instead of polynomial O(N*M).
