## 2025-03-05 - Optimizing Array Filtering in React
**Learning:** In the `App.tsx` component, the `filteredBots` array was being derived on every render. The `searchQuery.toLowerCase()` call was inside the `.filter` loop, meaning it was redundantly executing O(N) times per render. In addition, the more expensive string `.includes()` checks were executing before the cheaper `statusFilter` check. Combining `useMemo` with pulling the invariant string operation out of the loop and ordering conditional checks by performance cost resulted in a 3x speedup in isolated benchmarks.
**Action:** Extract expensive invariant derivations (like `.toLowerCase()`) outside of tight `.filter()` or `.map()` loops. Wrap derived state arrays in `useMemo` and order inexpensive conditional checks before expensive ones within iterators.
