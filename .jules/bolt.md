## 2024-05-30 - useMemo on array filtering for React performance
**Learning:** In a React functional component containing high-frequency event handlers or complex data models, constantly re-filtering large arrays on every render (like `bots.filter(...)`) causes unnecessary CPU cycles and can degrade interface responsiveness, even if the filter logic itself is simple. The component re-evaluates the array during every render pass.
**Action:** Wrap filtering logic and derived state inside `useMemo` so that the recalculation only occurs when the dependencies (e.g. `bots`, `searchQuery`, `statusFilter`) actually change. Also, moving invariant conversions like `searchQuery.toLowerCase()` outside the `.filter` callback inside the `useMemo` ensures they're only computed once per memoization rather than N times per array element.
